# Repository branding

`two-man-banner.png` is the banner supplied by Jason for the repository README on November 6, 2026. The original 2048 × 682 PNG is used without cropping or modification. It depicts the Season 2 mascots beside a golf course and two golf bags.

`two-man-mark.png` is the existing Season 2 mascot: two golf balls in sunglasses, with a flat cap on the left and a bucket hat on the right. The standalone mark is retained as a reference asset.

Copied without modification from [`preview/public/two-man-mark.png` at `8cd26d85cae60a024fe3f057486de0bbb83932b1`](https://github.com/jcb79107/the-two-man/blob/8cd26d85cae60a024fe3f057486de0bbb83932b1/preview/public/two-man-mark.png), where it is used by the Season 2 UI. This is a documentation asset, not a replacement for the production app's `public/two-man-logo.png`.

Historical design notes and runtime assets remain with the app versions they document. GitHub's repository description and social-preview image are separate repository settings; this change does not modify them.
